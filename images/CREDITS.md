# Image credits

Stock photographs used until The Smashery has its own food photography. Every image
here is **CC0 1.0** (public domain dedication): free for commercial use, no attribution
required. Sources are listed anyway so each file can be traced and replaced.

`og-share-1200x630.jpg` (the link preview for WhatsApp and social shares) is the hero
photo under the same scrim, with the wordmark set in Archivo. Variants are built by
`tools/images.mjs`.

These are not photographs of The Smashery's food. The site says "Pictures are for
illustration" wherever they appear.
